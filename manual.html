00 · What this is

JB-01 is a drum machine, a bass sequencer, eight keyboard voices, a mic looper, a mixer and a session recorder — in one HTML file. There is no installer, no build step, no plugin and no account. Open it in a browser and it works.

There are also no samples. Every sound you hear is synthesised in the browser as you play it: the kick is a pitch-swept sine, the snare is noise through a band-pass, the hats are noise through a high-pass. That is why the whole instrument is a few dozen kilobytes and why you can retune any drum without it sounding stretched.

What works where

SoundEverywhere. Web Audio is in every current browser. On phones and tablets you must tap once before anything makes noise — that is a browser rule, not a bug.
MIDI keyboardChrome and Edge only. Firefox needs a preference switched on (see section 09). Safari and iOS have no Web MIDI at all — everything else still works, you just click instead of play.
MicrophoneNeeds https:// or localhost. On a plain http:// address the browser will refuse, silently.
Saving a sessionDownloads as a .wav through the browser. If you are running the optional local server it writes straight to a folder instead — section 09.
Nothing you make leaves your machine. There is no server involved in playing it, no analytics, and no upload. Close the tab and it is gone — so if a session mattered, record it.

02 · The voice editor

The eight drums are not recordings, so they are not fixed. The strip under the drum grid edits whichever voice is selected — click a track name on the left of the grid to select it, and the name turns to mark which one you are holding.

TunePitch, in semitones, up or down. This moves the whole voice, including the noise components, so it stays coherent rather than sounding sped up.
DecayHow long the sound takes to die, as a percentage of that voice's natural tail. 40% turns a kick into a click; 200% turns it into a boom.
LevelHow loud this one voice is, independent of the drum channel in the mixer.
MuteSilences the voice while keeping its pattern. The track name greys out so you remember it is still programmed.
ResetBack to the factory value for that voice. Only the selected one.

Changing Tune, Decay or Level plays the voice once so you can hear the edit while the sequencer is stopped.

If you've never done this before

The fastest way to understand it is to break something on purpose. Select TOM, pull Tune down to about −7 and Decay up past 150, and you have a floor tom instead of a rack tom. Select KICK, pull Decay down to 40, and the room disappears from underneath your pattern. Select HAT and push Tune up — it gets thinner and more brittle, because you are moving the noise band, not stretching a recording.

This is how the same eight voices become a different machine. A 909 and a 606 are largely the same ideas at different tunings and decays — you have the same two knobs they had. Retune the whole kit down and shorten everything and you are in 606 territory; lengthen the kick and open the hats and you are closer to a 909.
Voice settings are not saved. They live in the page, and reloading returns everything to factory. If a kit is working, record the session before you touch anything else.

03 · The mixer

Five sources plus a master, each with a fader you drag vertically and an M button. Drag the fader itself — up is louder.

DrumsAll eight drum voices together, after their individual Level settings.
BassThe bass sequencer and the bass synth if you are playing it from the Akai.
KeysThe melodic voice — whatever preset the KEYS bar is set to.
MicLive microphone, only audible when Live Mic is on.
LoopThe recorded one-bar loop.
MasterEverything, after the limiter. Starts at 70%.

Four of the channels stop at 150% and the loop channel goes to 250%. That is deliberate: a loop recorded from a quiet source can be far below everything else, and without the extra headroom you could never bring it up to sit with the drums.

Master starts at 70%, not 100%. There is a limiter on the output catching peaks, and starting below full means the limiter is shaping the loud moments rather than fighting the whole mix. If you want it louder, turn up your speakers before you turn up the master.

What mute actually does

The M buttons mute the channel, not the part. A muted channel is still running, still being scheduled, and still lands in a session recording — as silence. That matters if you are recording: muting Drums for the last minute gives you a minute of drumless recording, exactly as you heard it. It is a performance control, not a way to remove something from the file afterwards.

Muting a channel greys its name and value. It is independent of the per-voice Mute in section 02 — that one silences a single drum, this one silences the whole bus.

05 · Playing notes over the beat

The KEYS bar turns the Akai into a small melodic instrument you can play while the beat runs. It's built so that you cannot play a wrong note.

Scale lock — the important one

Normally a keyboard gives you all twelve notes, and most combinations of them sound bad. That's the thing that makes playing hard when you're starting out.

With SCALE LOCK on, every physical key is remapped to the nearest note of the chosen scale. The out-of-tune notes simply aren't reachable. Press keys in any order, at any speed, and it will sound musical — because the notes that could clash have been removed from the keyboard entirely.

Adjacent keys become adjacent scale steps, not semitones. So running your finger up the keyboard plays a melodic run rather than a chromatic slide. Turn the lock off later, when you want the other notes back.

Which scale to pick

Pentatonic minorStart here. Five notes, and essentially every combination of them works together. It's the scale behind most blues, rock and hip-hop riffs. Very hard to make sound wrong.
MinorSeven notes. Darker, more melancholy, a bit more room to make a choice you don't like.
Pentatonic majorFive notes, bright and open. Folk and pop.
MajorSeven notes, the standard happy sound. The least forgiving of the five.
DorianMinor with one note lifted. Jazzy, slightly wistful.

KEY sets which note the scale starts from. It changes the mood without changing the relationships — the same scale in a different key sounds the same, just higher or lower. The bass grid follows it too, so your bass line and your playing are always in agreement.

The eight sounds

For beats and house:

E.PianoSoft, bell-like, medium sustain. The most forgiving — good for chords and for finding your way around.
RhodesWarmer and rounder than E.Piano, with a longer tail. The classic deep-house keyboard sound — play slow chords and let them ring.
House StabThree detuned saws with the filter slamming shut. This is the short chord jab you hear on every deep-house record. Play it on the off-beats.
House OrganDrawbar organ tone, sustained. Good for held chords underneath a beat, or bouncy repeated stabs.
PluckShort and percussive. Good for fast repeated notes and riffs that sit inside the beat.

For ambient:

GlassAn inharmonic bell with a long shimmering tail. Play sparse single notes and let them overlap — you barely need a beat at all.
PadSlow to fade in, long to fade out. Hold a few keys and it becomes a sustained wash under everything.
DroneThe most ambient of them: nearly a second to swell in, four seconds to fade. Hold two or three notes, turn the beat off entirely, and it becomes the whole piece.
Keys volBalance against the drums and bass.
OctaveShifts your whole playing range up or down. Low for basslines, high for melodies over the top.
Two recipes to try. Ambient: press CLEAR to silence the drums, pick DRONE or GLASS, set the scale to pentatonic minor, hold two or three notes and let them overlap. Add a little delay. Deep house: kick on steps 1/5/9/13, open hat on the off-beats, HOUSE STAB on the keys, and play short chords slightly after the beat rather than on it.

If you've never done this before

A few things that will make it sound better immediately, none of which require knowing any theory:

Use fewer notesTwo or three notes repeated with confidence sound better than lots of notes. Almost every memorable riff is very short.
Leave gapsSilence is part of it. Play on some beats and not others; the rhythm of when you play matters more than which notes.
Repeat yourselfPlay the same little phrase around and around. Repetition is what turns notes into a hook.
Land on the beatTry hitting a note exactly when the kick drum does. Then try deliberately between kicks. Both feel different, and noticing that difference is most of rhythm.
Record itHit Rec Session and just play for two minutes without stopping. You'll keep the accidents worth keeping, and accidents are where most ideas come from.
Set the MIDI dropdown to DRUMS + KEYS and you get both at once: the bottom of the keyboard fires drums, the top plays notes. Left hand rhythm, right hand melody.

06 · The mic

Any microphone or line source works — a USB interface, a built-in mic, or something plugged into the line-in. If the device has its own effects, they are processed in the hardware, before the signal reaches the computer. JB-01 just receives whatever comes out: change the effect on the device and you'll hear it change here.

The two mic buttons in JB-01

Live MicPasses the mic straight through to the speakers, routed through the filter and delay. Talk, sing, make noise — no recording, no looping. Turn the delay up and speak into it.
Rec LoopCaptures exactly one bar and loops it underneath everything, forever, until you clear it. Press it while the sequencer is playing and it waits for step 1 so the loop lands in time.
Clear LoopWipes the loop.
InputWhich input to use. Pick Line In — not the iMac's internal microphone.
Mic vol / Loop volLevels for the live mic and the recorded loop, separately.
Feedback. The iMac's speakers sit right next to its line-in. With Live Mic on you may get a howl. Use headphones — plug them into the left-hand jack — and the problem disappears entirely.
Input level check
not tested

Speak into the mic. You want the bar dancing around the middle. Barely moving means turn the device up; pinned to the right means turn it down — that's distortion.

07 · Recording a session

Press Rec Session and JB-01 captures the complete mix — drums, bass, your loop, live mic, anything you play on the Akai — as it happens. Press it again to stop, and a .wav file downloads automatically, named with the date and time.

Format16-bit stereo WAV at your system rate. Opens in GarageBand, QuickTime, anything.
SizeAround 10 MB per minute. The counter shows elapsed time and size as you go.
LimitStops itself at 15 minutes so it can't quietly eat all your memory.
It records what you hear, not what's programmed — so tweaking the filter, muting a track, or playing live all land in the recording. Treat it as a performance capture, not a bounce.

08 · Auto Set

Press Auto Set and the machine starts playing itself, indefinitely. It writes into the same drum grid and piano roll you use by hand, one bar ahead of the playhead — so you can watch the set being written while you hear it. Leave it on for four hours and it will still be going, and it will not have repeated itself.

Why it isn't just Random on a timer

Random rolls dice every time you press it. Auto Set runs an arrangement. Underneath is a single number — energy — that decides how much is allowed to play, and a small state machine that moves that number around in a shape a set actually has:

introBass and a soft hat. The kick hasn't arrived yet.
grooveThe main body. Kick, clap, offbeat hat, a rolling bass. Runs 16–32 bars.
buildEnergy climbs, the filter opens, the delay dries out, hats go to sixteenths.
peakEverything at once. Ghost kicks, rim sixteenths, a rolling backbeat.
breakdownThe kick cuts, not fades. Filter closes, delay opens up, bass and hats float. Then it builds again.

The current section and a little energy meter sit in the readout at the top, next to the BPM.

The three rules that make it listenable

It repeatsA phrase is composed once and then played eight times, with a fill on the last bar. A groove that changes every bar isn't a groove.
It only moves on bar linesNothing ever changes mid-bar. Sections are whole 8-bar phrases.
It doesn't roll dice for the partsKick, clap and hat placements come from a small vocabulary that's correct for the genre. The dice only choose between good options.

The three genres

They differ in more than tempo. Each one has its own rule for which voices may enter and in what order, its own job for the bass, its own drum tuning, and its own pace of change.

Techno138 BPM, no swing, A minor. Opens with drums alone. The kick is tuned down with a long tail and owns the low end, so the bass barely appears — roughly a fifth as often as in House, and only near full energy, one note, never moving. Sections run long: it dwells rather than develops.
Rave148 BPM, no swing, F# minor. Harder and faster. Kick tuned lower still and hitting harder, hats denser earlier, claps sooner. Almost no bass at all — a stab carries the hook instead.
House122 BPM, heavy swing, F major. Opens with bass and chords, drums join later. The bass is the tune here: syncopated, with octave lifts, in from the first bar. Diatonic seventh chords play on the offbeats and change every bar, so it moves through harmony instead of looping. Sections are short.

Changing genre

Switching genre mid-set is a mix, not a cut. The readout shows the pending genre with an arrow, the change lands on the next eight-bar phrase line, and the tempo glides across rather than jumping. The energy dips for a bar as it lands, so it reads as a blend.

Playing along with it

Auto Set owns the drums and the bass, plus tempo, swing, the master filter, the delay and the bass cutoff. It never touches your keys, your mic, your loop or the mixer. The intended way to use it is to leave it running and play over the top: it's a rhythm section that never stops and never complains.

The readout shows the key it's working in, e.g. A min · D. The first part is the scale, and it does not change — leave Scale Lock on and every key on the Akai will be in key. The part after the dot is where the bass has moved to, which is the chord you're currently over.

Pressing Clear or Random switches Auto Set off and hands you back the controls. Whatever bar it was on stays in the grid, so if it played something you liked, stop it and keep it.

Recording works exactly as normal, so Rec Session during an Auto Set gives you a 15-minute mix of a set you didn't have to play. Turn on Live Mic and talk over it if you want a radio show.

09 · Running it locally

Everything works from a plain web address. Running it on your own machine buys you three things: recordings that write straight to a folder instead of the downloads pile, a Show in Finder button that actually opens it, and a microphone that is allowed to work over http://.

Start the server

Clone the project and run the small Python server that ships with it, pointing it at the folder holding index.html:

JB01_DIR=$PWD python3 server/serve.py — then open http://localhost:8080.

Without JB01_DIR it serves the folder the script itself is in.

It serves the page with caching off, accepts the finished .wav on /save and writes it into recordings/, and answers /reveal by opening that file in the Finder. It listens on 127.0.0.1 only, so nothing is exposed to your network.

It must be http://localhost. Opening the file directly with file:// loads the page but the browser will block the microphone and Web MIDI, and you will get an instrument with no input.

Web MIDI in Firefox

Firefox ships Web MIDI switched off. Open about:config, set dom.webmidi.gated to false, and restart. Chrome and Edge need nothing — they will simply ask permission. Safari and iOS have no Web MIDI at all and no preference to change.

Making it feel like an app

Any browser will do, but a dedicated profile launched in kiosk mode against localhost:8080 gets you a window with no address bar, no tabs and no chrome — which is the difference between using a web page and using an instrument. On macOS, wrapping that command in an .app bundle puts it in the Dock like anything else.
